# Key3 球稳定性调参指南

## 问题描述

Key3任务：小车从A点启动，沿1.5m直线到B点，时间≤8秒，球保持在中心±1cm。

**现象**：启动加速时，球位置超过±1cm，且球大部分时间在O点**前面**（不符合惯性定律）

**根本原因**：
- 球控制器没有车体加速度前馈（`BallBalance.h:16`明确说明）
- 车体以300 mm/s²加速，球控制器只能被动响应位置偏差
- 检测到球往后 → 摆杆前倾加速球 → 过度补偿 → 球冲到前面

## 方案对比

### 方案1：降低启动加速度（推荐首选）

**调整参数**：`K44 150` (从默认300降到150 mm/s²)

**时间验证**：
- 加速到400 mm/s用时：2.67秒
- 加速距离：534 mm
- 匀速距离：966 mm，用时2.42秒
- **总时间：5.09秒** ✓ 远低于8秒

**优点**：
- 最简单，改一个参数
- 给球控制器更多时间稳定
- 时间充裕，安全余量大

**调试步骤**：
```
K44 150    # 设置加速度150 mm/s²
```

如果还不够稳定，可以进一步降低：
```
K44 100    # 加速度100，总时间5.75秒
K44 80     # 加速度80，总时间6.5秒
```

### 方案2：增加球控制器阻尼

**调整参数**：
```
K31 1.5    # 位置Kp从2.0降到1.5，响应更柔和
```

或者：
```
K32 0.20   # 速度Kp从0.25降到0.20，摆杆动作更小
```

**优点**：不影响行驶速度
**缺点**：可能影响恒速时的球控制精度，需要多次调试

### 方案3：组合调整（推荐用于极限优化）

先降低加速度，再微调球控制器：
```
K44 120    # 加速度适中
K31 1.8    # 位置Kp微降
```

## 当前默认值

| 参数 | ID | 默认值 | 说明 |
|------|-----|--------|------|
| `MotionLine_TuneAccelerationMMps2` | K44 | 300 mm/s² | 启动加速度 |
| `BallBalance_TunePositionKpPerS` | K31 | 2.0 /s | 球位置P增益 |
| `BallBalance_TuneVelocityKpDegPerMMps` | K32 | 0.25 deg/(mm/s) | 球速度P增益 |
| `BallBalance_TuneVelocityKiDegPerMM` | K33 | 0.20 deg/(mm·s) | 球速度I增益 |

## 快速测试流程

1. **连接串口调试**，启动小车程序

2. **设置加速度**：
   ```
   K44 150
   ```

3. **运行key3测试**：按KEY1启动

4. **观察球位置**：
   - 启动阶段球是否还冲到前面？
   - 稳定后球能否保持在±1cm？
   - 总时间是否<8秒？

5. **根据结果调整**：
   - 球还是超出±1cm → 继续降低K44到100或80
   - 球很稳定但时间紧张 → 提高K44到180
   - 恒速时球控制不够精确 → 微调K31/K32

## 理论背景

**为什么降低加速度有效？**

球的运动方程（简化）：
```
球相对车体的加速度 = 摆杆倾角×k - 车体加速度
```

当车体加速度大时：
- 球往后偏 → PID让摆杆前倾 → 球加速向前
- 但PID不知道车体在加速，只能通过位置误差间接响应
- 响应滞后 + 过度补偿 = 振荡

降低加速度后：
- 位置误差变化慢
- PID有更多时间调整
- 减少过冲
