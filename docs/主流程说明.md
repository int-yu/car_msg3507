# 当前主流程

本文件描述当前固件实际运行的流程。唯一入口是 `main.c`；`Application/Core/Main26H.c` 是保留的历史入口，不参与当前构建流程切换。

## 启动与循环

启动时，`main()` 依次初始化 `App`、26H 巡线控制器、定时巡线、摆球、目标采样和显示菜单，然后开启中断。

`App_Init()` 负责当前任务所需的硬件与服务：板载 LED/蜂鸣器/按键、六路红外、双轮电机、舵机、调试串口、K230、里程计、步进与摆杆、OLED、MPU6050 航向、调试命令、遥测、任务计时和运动管理器。未使用的 F32C/Gimbal 不初始化；UART1 没有实例化，CarLink 仅保留软件协议兼容性。

主循环按 100 Hz 执行：

1. `App_Update()` 更新计时、航向、里程、六路红外、步进、按键、K230/钢球位置、调试命令与底盘运动。
2. `Accomplish26H_Update()` 与 `TimedLineRun_Update()` 更新巡线任务。
3. 根据按键或网页命令更新菜单状态及任务启动/取消。
4. 更新目标采样、摆球控制、遥测、摆杆执行器与 OLED。

## 菜单与按键

- 空闲菜单显示要求 2～6；`KEY1` 循环选择，`KEY2` 确认。
- `KEY3` 在任意阶段取消当前任务、停止相关计时并返回菜单；硬件就绪后恢复默认 O 点保持。
- `KEY1 + KEY2` 是物理急停，等同网页 `C0`：立即停止底盘、摆球和步进。
- 网页/PC 使用 UART2（`Serial1`）；K230 视觉使用独立 UART0（`Serial3`）。
- OLED 运行页使用 8×16 字体显示要求号和计时，计时精度为 0.1 秒。

## 任务流程

| 要求 | 启动方式 | 执行内容 |
|---|---|---|
| 2 | 菜单选中后按 `KEY2` | `Accomplish26H` 单圈巡线；保持钢球在 O 点。达到 `h2arm` 后，以连续相邻三路红外横线确认终点并主动刹车。 |
| 3 | 选中后按一次 `KEY2` 进入准备，再按一次 | `BallSequence` 在 -50 mm 至 +50 mm 间摆球扫描并计时。上电空闲、视觉和步进就绪时默认保持 O 点。 |
| 4 | 选中后按一次 `KEY2` 进入准备，再按一次 | `TimedLineRun` 巡线，500 mm/s、13 s；保持钢球在 O 点。 |
| 5 | 菜单选中后按 `KEY2` | `TimedLineRun` 巡线，400 mm/s、30 s；保持钢球在 O 点。 |
| 6 | 选中后按 `KEY2` 开始采样；目标锁定后再按一次 | `BallTargetCapture` 锁定 K230 目标位置，`BallSequence` 保持该目标，再以 400 mm/s、30 s 巡线。 |

## 关键运行约束

- `App_Update()` 每拍只采样一次六路红外；巡线、任务、显示与遥测读取同一帧数据。
- 摆杆启动后需先取得 3 帧有效 MT6816 PWM，`BeamActuator` 将实测角度作为本次上电的水平零偏；启动前手动将摆杆放至平衡位置。
- 要求 2 的终点里程阈值由 `K42`（`h2arm`，mm）控制，允许下限为 5000 mm；只有里程严格大于该值且横线确认成立时才停车。
- 要求 6 默认连续采集 8 帧、平均值容差 ±5 mm；参数定义在 `Application/Control/BallTargetCapture.h`。
